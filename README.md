# LEGENDS XI

引退した名選手を集め、ベストイレブンを編成して戦うブラウザ向けサッカーカードゲームです。ビルドツールやバックエンドを必要とせず、静的ファイルだけで動作します。

## 主な機能

- 12名のレジェンド選手と3段階のカードレアリティ
- ポジション絞り込み・並べ替え・選手詳細
- 所有選手からのベストイレブン自動編成
- チーム総合値を反映したランクマッチシミュレーション
- 通貨、パック開封、重複カード補償
- `localStorage` による進行状況の自動保存
- キーボード操作、レスポンシブレイアウト

## 起動

```bash
python3 -m http.server 4173
```

ブラウザで <http://localhost:4173> を開いてください。

## データの初期化

ブラウザの開発者ツールで次を実行し、ページを再読み込みします。

```js
localStorage.removeItem('legends-xi-save-v2');
```
